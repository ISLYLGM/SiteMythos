# ☕ MYTOS — Café, sabor e lendas.

O **MYTOS** é um projeto acadêmico que une **café, mitologia e tecnologia** em uma experiência pensada para toda a família.

Inspirado em diferentes culturas e mitologias, o projeto apresenta um café temático com bebidas e comidas inspiradas em personagens e histórias mitológicas, além de uma identidade visual acolhedora, divertida e acessível.

## ✨ Sobre o projeto

O MYTOS foi desenvolvido como um projeto que integra **design, desenvolvimento web e desenvolvimento Android**, criando uma experiência digital para os clientes do café.

O projeto conta com:

* ☕ **Cardápio digital** com bebidas, doces e salgados inspirados em mitologias;
* 📱 **Aplicativo Android** para explorar o MYTOS;
* 🛍️ **Sacola de compras** para organizar os produtos escolhidos;
* 👤 **Perfil do usuário**;
* ♿ **Recursos de acessibilidade**;
* 🦊 **Três mascotes** inspirados em diferentes culturas;
* 🌎 Uma identidade visual inspirada em mitologias do mundo.

## 🐺 Mascotes

O MYTOS possui três personagens que fazem parte da identidade do café:

* 🐺 **Iago** — um lobo-guará brasileiro;
* 🐈‍⬛ **Bast** — uma gata inspirada na cultura egípcia;
* 🦊 **Mika** — uma kitsune inspirada na cultura japonesa.

Os mascotes representam diferentes culturas e ajudam a tornar a experiência do MYTOS mais divertida e acolhedora.

## 🍰 Cardápio

Entre os produtos desenvolvidos para o projeto estão:

* ☀️ **Café de Apolo** — R$ 14,90
* 🌊 **Néctar de Poseidon** — R$ 16,90
* 👑 **Torta de Hera** — R$ 18,90
* 🦊 **Chá de Kitsune** — R$ 13,90

Cada produto possui uma inspiração mitológica própria, conectando o cardápio à temática do café.
